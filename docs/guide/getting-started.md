# 什么是 AI Code Review

AI Code Review 是一款**本地运行**的 AI 驱动代码审查命令行工具。它通过 Git Hooks 无缝接入你的开发工作流，将代码变更发送至 LLM 大语言模型后端进行智能审查，帮助你在提交前发现潜在问题。

:::tip 为什么选择本地运行？
所有代码审查均在你的本地机器上完成，代码无需上传至第三方云端服务。配合 Ollama 本地模型，你可以实现完全离线的代码审查体验，保障代码安全与隐私。
:::

## 工作原理

AI Code Review 采用**两阶段审查流水线**设计：

1. **Pre-commit 快速筛查**：在你执行 `git commit` 时，通过 Git pre-commit 钩子触发快速审查。仅检查 ERROR/CRITICAL 级别的规则，使用精简提示词实现低延迟响应。如发现阻塞性问题，将直接阻止提交。

2. **Post-commit 深度审查**：提交完成后，通过 post-commit 钩子在后台异步执行全量审查。使用完整提示词、全部规则和记忆系统提醒，生成详细的 JSON + Markdown 审查报告。

:::warning Pre-commit 安全策略
Pre-commit 阶段遵循"**失败开放**"原则——当 LLM 后端不可用、超时或发生错误时，审查会自动放行，绝不会因为基础设施故障而阻止你的提交。
:::

## 核心能力

| 能力 | 说明 |
| --- | --- |
| **Pre-commit 拦截** | 提交前快速筛查，发现安全漏洞、凭证泄露等严重问题直接阻止提交 |
| **Post-commit 深度审查** | 提交后异步执行完整审查，生成详细报告和代码修复建议 |
| **自定义规则** | YAML 格式规则文件，按文件扩展名自动匹配，灵活定制审查标准 |
| **记忆系统** | 跨次审查跟踪重复问题，计算文件风险分数（0-10），智能衰减提醒频率 |
| **通知中心** | 终端 Inbox 收件箱 + HTML 可视化仪表盘 + 系统弹窗通知三通道提醒 |
| **抑制管理** | 对已知的可接受问题进行抑制，避免重复通知干扰，支持模糊匹配 |

## 支持的 LLM 后端

AI Code Review 支持两类 LLM 后端：

### Ollama（本地部署）

在本地运行开源大语言模型，完全离线，代码不出本机。适合对代码隐私有严格要求的团队和个人。

### OpenAI 兼容 API

支持所有兼容 OpenAI Chat Completions 接口的 API 服务，包括但不限于：

- **智谱 GLM（Zhipu）** — 国产大模型，中文理解能力强
- **DeepSeek** — 高性价比代码理解模型
- **通义千问（Tongyi Qwen）** — 阿里云旗下大模型服务
- 其他任何兼容 OpenAI API 格式的服务

:::tip 如何选择后端？
- 追求**隐私安全**：选择 Ollama 本地部署
- 追求**审查质量**：选择 DeepSeek 或智谱 GLM 等云端模型
- 两者也可以搭配使用：Pre-commit 用本地模型保证速度，Post-commit 用云端模型获得更详细的审查结果
:::
